  ## 2. Architecture & Layer Map

  ```
   MT5 (Exness feed)
     |  tick
     v
   Layer1 tick_engine -> Layer2 DETECTION (velocity_*, displacement_*, peak_detector, event_detector)
                      -> Layer3 CONTEXT (regime_engine, level_tracker, liquidity_engine, location_engine,
                                         mtf_context, market_context(_builder), live_state)
                      -> Layer4 ENTRY/EXIT (entry_state_machine, exit_engine, adaptive_exit,
                                            velocity_trailing, trade_state_engine, trade_health_monitor,
                                            trade_executor)
   Layer5 daemon.py + reversal_model.py orchestrate;  Layer6 api_server.py = dashboard/WS
  ```
  Execution transport (dual-terminal): Feed=Exness MT5; Orders=separate MT5 via `mt5_order_bridge.py` (subprocess) or `execution_client.py` -> `windows/execution_bridge.py`. WSL dashboard data via `mt5_bridge_client.py` -> `windows/mt5_bridge.py`.

  ## 3. End-to-End Runtime Sequence

  1. **Launch** — `cli/main.py`/`run.py` build config, call `AxonDaemon`; `api_server.start_dashboard()` starts FastAPI/uvicorn on a bg thread.
  2. **Construction** (`AxonDaemon.__init__`, daemon.py:50) — wires TickEngine, LiveWorldState, LiveMarketEvidence, ReversalModel (builds VelocityNormalizer, DisplacementEngine, EntryStateMachine, location/trade-state), MT5TradeExecutor x2, VelocityTrailingManager, ExitEngine+AdaptiveExitManager, DisplacementNormalizer; starts `_slow_poll_loop`.
  3. **Cold start** (`start`, daemon.py:622) — mt5_initialize (Exness) -> start_bridge (orders) -> re-adopt positions -> live_state/live_evidence initialize from history -> sync_levels -> wire tick callbacks -> tick_engine.start() -> `_event_loop()`.
  4. **Tick ingestion** — TickEngine polls MT5 (ms time_msc), builds candles, computes order imbalance, fires `_on_tick`.
  5. **State update** (`_on_tick`, daemon.py:821) — live_state.on_tick + live_evidence.on_tick (regime, sessions, S/R, level behaviour); sync_levels.
  6. **Location** — `location_engine.compute(...)` -> LocationContext (distance-to-S/R in ATR, room, at_structure).
  7. **Detection/entry** (`reversal_model.on_tick`, reversal_model.py:123) — VelocityNormalizer.update -> NormalizedVelocity (velocity pips/s, percentile, z, tick_efficiency, decay_ratio, is_unusual/is_decaying/is_accelerating); DisplacementEngine.update -> DisplacementState (ratio, IMPULSE/TRAP/ABSORPTION/EXHAUSTION/COMPRESSION); regime+MTF; EntryStateMachine (IDLE->ANOMALY->ARMING->TRIGGERED) -> EntryDecision; also ExitDecision, trade_health. Returns EngineSnapshot.
  8. **Telemetry** — inject context into snapshot; broadcast trigger_metrics/tick/trade_state/location_context.
  9. **Queue** — valid entry -> `{type:entry}`; should_exit/ADJUST_SL -> `{type:exit}` onto event_queue.
  10. **Inline trailing/closure** (tick thread) — `_manage_trailing_stops` runs VelocityTrailingManager.on_tick + ExitEngine.evaluate; `_check_for_closed_positions` reconciles tickets.
  11. **Entry exec** (main thread `_event_loop`, daemon.py:1066) — pause/cooldown/direction gates -> trade_executor_opt.execute_signal -> register with trade_state_engine, reversal_model.register_trade, trade_analytics.record_entry.
  12. **Exit exec** — reconcile is_position_live() -> ADJUST_SL or CLOSE_NOW via bridge/execution_client -> record_exit, clear_trade.
  13. **Persistence/API** — closed trades -> reports/signals.jsonl; dashboard caches + pushes /ws; /api/logs/trades merges open+close.
  14. **Shutdown** (`stop`, daemon.py:1430).

  Backtester mirrors 4-12 deterministically: interpolated ticks (0.05s for VelocityNormalizer) -> same stack -> markdown report.

  ## 14. Improvement & Completion Roadmap — Velocity Reversal System

  Goal: auto-detect velocity behaviour on reversals at different market stages. Blocks exist & are strong; gaps are wiring, stage-consistency, symbol-robustness.

  **Phase 0 Cleanup (no behaviour change):** delete L2 prototype + L3 vendor tree + artifacts; rename LLM labels; lint pass (unused imports, __main__ blocks, deprecated utcnow/get_event_loop).

  **Phase 1 Fix decision wiring:** fix bugs #1-3,#6,#11; decide entry path — recommend **wiring EntryStateMachine.evaluate_with_context** (its stop-hunt/lag/confidence/agreement filters are dead today and are the richest stage-aware reversal guards) or delete entry_gate; unify trailing (merge velocity_trailing + AdaptiveExitManager trail), fix #4/#5.

  **Phase 2 Regime-consistent stages:** make PeakDetector regime-aware (static thresholds today); corroborate peaks with DisplacementState EXHAUSTION/TRAP; centralize one canonical reversal-stage label (displacement_phase + regime sequence + reversal_lag); wire real LevelBehaviorTracker (absorption/rejection velocity/attack quality) into stop-hunt & agreement.

  **Phase 3 Symbol/ATR robustness:** replace hardcoded pips (mtf 80-pip, regime 5-pip, live_state pip bands + magic prices, velocity_trailing pip) with ATR/symbol-relative; implement real location_engine.distance_to_liquidity from liquidity_engine.
